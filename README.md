# Predicting Asset Returns: Machine Learning with Free Data

**P. Edward Herman**

📄 [Read the paper (PDF)](Herman_Returns_ML.pdf)

## Abstract

> In this paper, we model expected stock returns from a combination of various
> freely available internet data sources. When predicting expected stock returns,
> the go-to data for new ideas and benchmarking comes from CRSP and Compustat.
> However, this data requires a license, which the common retail investor may not
> have. We aim to investigate what gains can be had in prediction power by using
> publicly available data and machine learning.
>
> Secondary, we aim to understand which publicly-derived features are important in
> making predictions of asset returns. Locally, the model pinpoints the features
> most important in predicting returns on a single equity. Traditionally, the model
> also determines significant features on a global, aggregate level.

## Later work

The feature-engineering approach in this paper was later re-implemented
independently and tested walk-forward over 13 years (2013–2026) on point-in-time
SEC filings and a survivorship-free universe. A summary of that study is
available on request.
